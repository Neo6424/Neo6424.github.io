- **활동**: WhiteHat School 4기 팀 프로젝트
- **형태**: 8인 연구팀 (V3 백신 탐지 실험 담당)
- **성과**: ACK 2026 학부생 논문 게재

## 1. 연구 소개

WhiteHat School 4기 팀 프로젝트에서 8인 연구팀과 함께 악성 페이로드의 변환 및 로딩 방식에 따른 상용 안티바이러스 탐지 특성 분석을 진행했다.

상용 안티바이러스는 파일의 시그니처를 이용하는 정적 탐지뿐 아니라, 실행 중 발생하는 행위와 메모리 내 코드 등을 분석하는 다양한 탐지 기법을 사용한다.

본 연구에서는 동일한 악성 페이로드라도 암호화 및 로딩 방식에 따라 탐지 결과가 달라질 수 있다는 점에 주목했다.

이를 확인하기 위해 Quasar RAT와 Mimikatz를 대상으로 다양한 변환 및 로딩 방식을 적용하고, 상용 백신의 탐지 여부와 탐지 시점을 비교·분석했다.

## 2. 담당 역할 및 연구 과정

연구팀에서 V3 백신 탐지 실험을 담당했으며, 페이로드 로딩 방식과 안티바이러스 탐지 원리를 분석했다.

### ① 실험 환경 구축 및 초기 탐지 분석

- VMware 기반 Windows 11 개발·테스트 환경 분리
- Quasar RAT 테스트 파일 빌드 및 SHA-256 해시 검증
- V3 실시간 감시의 파일 접근 단계 탐지 결과 분석
- 탐지 시점과 진단 결과 기록

### ② 페이로드 로딩 및 프로세스 인젝션 실험

- Shellcode Loader와 Process Injection 구조 학습 및 구현
- Windows API를 이용한 프로세스 메모리 조작 및 실행 흐름 분석
- Donut을 활용한 .NET 페이로드 변환 과정 분석
- AMSI 검사 과정과 메모리 내 .NET 어셈블리 로딩의 관계 분석
- DLL Injection 및 AMSI API Hooking 관련 실험 수행

### ③ 추가 백신 탐지 실험

V3 실험 이후 Bitdefender를 대상으로도 탐지 실험을 진행했다.

페이로드가 파일 상태에서는 탐지되지 않더라도 실행 과정에서 행위 기반 탐지가 발생하는 사례를 확인하고, 탐지 시점에 따른 차이를 분석했다.

## 3. 연구 결과 및 성과

실험 과정에서 V3가 원본 Quasar RAT 파일을 실행 전 파일 접근 단계에서 탐지하는 것을 확인했다.

이후 로딩 방식을 변경한 특정 실험에서는 V3 탐지가 발생하지 않은 상태로 테스트 환경 내 실행 및 연결이 이루어지는 것을 확인했다.

반면 Bitdefender 실험에서는 파일 자체가 탐지되지 않더라도 실행 이후 행위 기반 탐지가 발생하는 사례가 관찰되었다.

이를 통해 동일한 페이로드라도 실행 방식과 백신 제품에 따라 탐지 시점 및 결과가 달라질 수 있음을 확인했다.

팀에서 수행한 실험과 분석 결과를 정리하여 ACK 2026 학부생 논문으로 게재했다.

## 4. 활동을 통해 배운 점

이번 연구를 통해 Windows의 프로세스 및 메모리 구조, Shellcode 로딩 방식, AMSI와 같은 보안 검사 메커니즘에 대한 이해를 높일 수 있었다.

또한 백신의 탐지 여부만 확인하는 것이 아니라, 어떤 단계에서 어떤 이유로 탐지가 발생했는지 분석하는 과정이 중요하다는 것을 배웠다.

특히 직접 실험 환경을 구축하고 로더를 구현하며 탐지 결과를 분석한 경험을 통해 악성코드 분석과 엔드포인트 보안 기술에 대한 실무적인 이해를 넓힐 수 있었다.
