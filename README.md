# Neo6424 블로그

GitHub Pages로 운영하는 개인 블로그입니다. 글은 공개 GitHub 이슈를 통해 코드 수정 없이 올릴 수 있습니다.

## 글 올리기

1. [블로그](https://neo6424.github.io/)에서 카테고리를 고르고 **글쓰기**를 누릅니다.
2. GitHub에 `Neo6424` 계정으로 로그인합니다. 제목 앞에 자동으로 들어간 `[개발]` 같은 카테고리는 그대로 두고, 그 뒤에 글 제목을 적습니다.
3. 본문에 내용을 작성하고 **Create**를 누릅니다. 이슈는 공개됩니다.
4. 블로그를 새로고침하면 글이 표시됩니다. GitHub API의 응답이나 브라우저 상태에 따라 잠시 지연될 수 있습니다.

예: 제목이 `[개발] 첫 프로젝트`이면 블로그의 개발 카테고리에 `첫 프로젝트`로 표시됩니다. 작성자 `Neo6424`의 열린 이슈 중 제목 앞의 카테고리가 아래 여섯 개 중 하나인 글만 게시됩니다. 다른 사용자의 이슈나 풀 리퀘스트는 표시되지 않습니다.

- `개발`, `CTF/Wargame`, `Bug Bounty`
- `블로그/기술문서`, `논문/컨퍼런스`, `공모전/자격증`

글을 수정하려면 블로그에서 글을 열어 **GitHub에서 수정하기**를 누르고, 이슈 본문이나 제목을 수정하면 됩니다. 글을 내리려면 GitHub에서 해당 이슈를 닫으세요. 다시 열면 다시 표시됩니다.

본문에서 문단, 줄바꿈, 제목(`#`), 목록(`-`), 굵은 글씨(`**`), 인라인 코드, 코드 블록, 링크와 이미지를 표시합니다. 이보다 복잡한 GitHub Markdown은 원본 GitHub 이슈에서 볼 수 있습니다. 글 목록은 GitHub API를 사용하므로 API 호출 제한이나 일시 장애가 생기면 기존 안내 글만 보이고 오류 메시지가 표시됩니다. 이 경우 잠시 후 새로고침하세요.

## 파일 구성

- `index.html`: 제목과 화면 구조
- `style.css`: 화면 디자인
- `posts.js`: 기본 안내 글
- `app.js`: 글 목록, 검색, 글쓰기 링크

저장소의 `main` 브랜치 최상위 폴더가 GitHub Pages 게시 원본입니다. 파일 변경을 커밋하면 사이트가 다시 배포됩니다.
